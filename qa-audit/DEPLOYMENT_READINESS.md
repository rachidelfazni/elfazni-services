## 5. إرشادات وخطوات النشر إلى بيئة الإنتاج الحقيقية (Deployment Instructions)

> **تنبيه أمني هام:** وفقاً لسياسات السلامة والحدود الصارمة، **لا يقوم Antigravity بالنشر التلقائي إلى خوادم الإنتاج المباشرة**. تقع هذه الخطوة على عاتق مسؤول النظام عبر تنفيذ الإجراءات التالية:

### الخطوة 1: تجهيز متغيرات البيئة (Production Environment Variables)
تأكد من ضبط المتغيرات التالية على خادم الإنتاج:
```bash
NODE_ENV=production
PORT=8080
JWT_SECRET="<generate-a-cryptographically-secure-random-secret>"
ADMIN_EMAIL_ALERTS="admin@elfazniservices.com"
WHATSAPP_OFFICIAL_NUMBER="+905521743444"
```

### الخطوة 2: بناء الأصول الإنتاجية (Build Production Assets)
```bash
npm run build
```
*سيقوم هذا الأمر ببناء واجهات الموقع العام ولوحة الإدارة في مجلد `dist/`، وبناء نظام الـ CRM في مجلد `crm/dist/` تلقائياً.*

### الخطوة 3: إدارة العملية عبر PM2 أو Docker (Process Management)
يوصى بتشغيل الخادم باستخدام مدير العمليات `pm2` لضمان إعادة التشغيل التلقائي وإدارة السجلات:
```bash
pm2 start server/index.ts --name "elfazni-services" --interpreter ./node_modules/.bin/tsx
pm2 save
```

### الخطوة 4: ضبط الوكيل العكسي (Nginx Reverse Proxy & SSL)
تأكد من توجيه حركة المرور HTTPS إلى المنفذ 8080 مع دعم WebSockets / SSE:
```nginx
server {
    server_name elfazniservices.com www.elfazniservices.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```
