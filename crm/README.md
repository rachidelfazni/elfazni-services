# الفزني CRM

نسخة مصدر من الإصدار المنشور da53e70، تشمل جهات الاتصال والديون والصور التسع للخدمات.

1. ثبّت Node.js 24.
2. انسخ `.env.example` إلى `.env` وأدخل كلمة مرور لحساب الإدارة المحلي.
3. نفّذ `npm ci` ثم `npm run dev`.

ملف البيئة مخصص للتشغيل المحلي. احفظه خارج أي حزمة تُنشر على الإنترنت.
لا يشمل الأرشيف بيانات متصفحك. انقلها من «النسخ الاحتياطي» عبر تصدير JSON واستعادته في النسخة الأخرى.
